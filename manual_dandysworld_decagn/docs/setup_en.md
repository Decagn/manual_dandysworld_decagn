## Dandy's World Options

The world options can be set in the player's Archipelago YAML. Toon and trinket selections use YAML lists:

```yaml
Final_Floor_Num: 20
Toons_Required: Any
Number_Of_Toons_To_Reach_Goal: 1
Starting_Toons: [Random]
Include_Toons: []
Exclude_Toons: []
Include_Trinkets: []
Exclude_Trinkets: []
Event_Twisteds: None
```
